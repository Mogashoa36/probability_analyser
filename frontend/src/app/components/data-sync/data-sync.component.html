Which access route?

The supported route is the official API (api.sofascore.com) with an API key set in app.sync.sofascore.api-key. The public web endpoint (www.sofascore.com) needs no key but is undocumented and sits behind bot protection - it answers HTTP 403 to anything that is not a browser, which includes most servers and CI runners.
